审查阶段建议先确定侧栏和常驻状态区的布局方案；首批同时解决目标面、结果来源、保存反馈、工程重连引导。第二批统一按钮、文字和窄屏布局。后台导入与AI控制单独实施，保留已有数据/编辑/保存契约并作针对性验证。当时仅写入审查记录；后续用户授权的第一轮实施与验证见本文顶部。
